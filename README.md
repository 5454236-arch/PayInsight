# PayInsight — Digital Payment Analytics Dashboard

A web-based Digital Payment Analytics project built with Python and Streamlit, designed to complement the Power BI analytics workflow.

## Features
- CSV upload
- Data cleaning and preprocessing
- KPI cards
- Payment method analysis
- Success/failed transaction analysis
- Daily and monthly trends
- Amount distribution
- City/category analysis
- Cleaned CSV export
- Synthetic demo dataset included

## Run on Streamlit Community Cloud

1. Upload this repository to GitHub.
2. Open Streamlit Community Cloud.
3. Sign in with GitHub.
4. Create a new app.
5. Select this repository and branch.
6. Set the main file to `app.py`.
7. Deploy.

No local installation is required for the deployed version.

## Important
The included dataset is synthetic demo data for academic development. Replace it with your approved project dataset before using real results in the final report.

## Power BI
Use `data/sample_transactions.csv` or your approved cleaned dataset in Power BI Desktop. Starter DAX measures are available in `DAX_Measures.txt`.
